# template_mobile_app

Une boîte à outils pour accélérer la création d’applications mobiles iOS et Android : ressources sélectionnées façon Awesome, composants réutilisables, recettes d’intégration et starters.

## État du projet

Phase de cadrage. Le dépôt contient pour l’instant le cahier des charges. Les composants et starters seront développés dans les étapes suivantes ; la stack de référence reste à choisir.

## Cahier des charges

Lire le [cahier des charges](docs/cahier-des-charges.md) : objectifs, 22 sections, priorités, contrat des composants, organisation cible, critères d’acceptation et feuille de route.

Les sections couvrent le démarrage, l’architecture, l’interface, la navigation, les écrans, les formulaires, l’authentification, les API, le stockage hors ligne, les permissions, les médias, les notifications, la recherche, les capacités natives, les paiements, l’accessibilité, la sécurité, les tests, la performance, la publication, les services métier et la maintenance.

## Principe de réutilisation

Partir d’un besoin, choisir une ressource adaptée à sa stack et intégrer un élément documenté. Les recommandations devront préciser leurs limites, leur licence et les versions réellement vérifiées.

## Prochaine étape

Choisir une stack de référence et constituer le catalogue des ressources prioritaires avant de construire le premier starter.
